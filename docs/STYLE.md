# THE GLUTONY — STYLE.md

## 1. Brand Identity

Name:
The Glutony

Genre:
Dark fantasy action platformer / monster evolution RPG

Core feeling:
- Forbidden power
- Hunger
- Evolution
- Fear
- Dominance
- Mystery

The player is not a hero.
The player is a monster trying to surpass every other monster and consume the world.

Visual inspiration:
- Dark fantasy
- Infernal worlds
- Ancient ruins
- Corrupted nature
- Demonic civilizations
- Biological mutations


---

# 2. Visual Direction

## Overall style

The visual style should feel:

- Dark
- Aggressive
- Mysterious
- Cinematic
- Ancient

Avoid:
- Cute fantasy
- Bright colors
- Cartoon feeling
- Clean futuristic UI


The world should feel like:
"A forgotten hell where monsters built their own civilization."

# 5. Logo Style

The logo should feel like:

A forbidden symbol.

Ideas:

- A monster claw forming the letter G
- A corrupted crown
- A mouth/fang symbol
- Ancient rune mixed with a creature shape


Logo feeling:

"Something powerful that should not exist."
